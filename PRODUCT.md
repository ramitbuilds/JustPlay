# JustPlay

Describe your game. Play it immediately.

For curious players who want to create and iterate on small 2D games without coding. AI writes original JavaScript rules and procedural Canvas artwork from the request. The app checks source syntax and startup, provides an isolated player, natural-language source edits, immutable versions and a local library.

There is no fixed list of genres, keyword routing or preset fallback in generation. Complex requests become compact prototypes with visible simplifications. Free inference quota, code budgets and model reliability remain real limits. Older saved preset games remain playable as legacy content. Credentials stay on the server; no account is needed for browser-local saves.
