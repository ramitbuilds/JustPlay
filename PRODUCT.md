# JustPlay

Describe your game. Play it immediately.

For curious players and hackathon visitors who want to create and iterate on small 2D games without coding. Success is a validated AI design, a playable level, an edit that changes mechanics and a saved version that reopens. Five supported families: platformer, runner, survival, basketball shootout and cricket batting. Basketball means aiming/charged shots and baskets; cricket means timed batting, runs and wickets. Unsupported genres receive a clear capability error instead of a renamed runner. No arbitrary code generation or AAA claims.

Explicit brief supplies the product context and delegates design decisions. Offline authored examples are a separate, honest entry point. Inference requires server credentials and available free quota. Local saves need no account.
