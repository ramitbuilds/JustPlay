# Investigation methods
Read current upstream https://github.com/morluto/rea README. REA MCP is not registered in this session; no attached CDP browser was supplied. Its desktop/native setup was not run. REA analysis itself did not run.

Tools actually used: Python urllib through the managed HTTP proxy for public HTML and one public bootstrap module; static text/link inspection. Public routes were fetched without authentication. No private APIs, credentials, backend prompts or source were extracted. Later Playwright QA targets our own app.

Instaplay frontend dependencies are public observations; generation architecture remains unknown. Research files are kept outside the repository to avoid redistributing competitor bundles.
