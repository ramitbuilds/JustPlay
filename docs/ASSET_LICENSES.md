Kenney Tiny Dungeon was considered (its page lists CC0), but download-link access returned 403. No Kenney or competitor artwork is included. Assets are generated locally without image APIs, stock purchases or protected franchise sprites. Rebuild original pixels with `python scripts/make_assets.py` (Python standard library only). The existing repository MIT license remains unchanged.

## Sports assets

`athlete.png` is original 16×16, four-frame pixel art generated by `scripts/make_assets.py`. `court.svg` and `stadium.svg` are original local 640×360 arena illustrations. `src/game/sports.ts` draws original ball textures, hoop/net/backboard, bat, wicket and aim/power aids through Phaser. All use the project MIT license; no external packs, paid image service, team branding or protected sports logos are used.

## Submission sprite library

`public/assets/library/{car,tree,coin,rock,player,ball}.svg` are original JustPlay vector sprites under the repository MIT license. They are preloaded as ImageBitmaps by the trusted app and transferred to the isolated player; model-generated code draws them with assets.image(id). They contain no game rules. No paid artwork, external model download, Kenney asset or 3D dependency ships in this 2D submission update.
