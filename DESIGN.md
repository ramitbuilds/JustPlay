# JustPlay design system

Creative playroom meets a precise editorial studio. The worlds, not dashboard chrome, carry the color.

- Paper #f4f2e9; ink #202c27; moss #2b5c42; acid #d8ed83; border #d3d7c9; muted ink #586457. Warm and legible in daylight.
- Space Grotesk for expressive display and UI, system sans fallback. Display 48–76px, section 28px, body 15–18px. Headings tracking -0.04em, balanced wrapping.
- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 72. Max content 1280px. Broad whitespace around the composer. Borders separate studio tools; no nested dashboard cards.
- Primary buttons ink with paper text, 48px targets; accent used for create. Radius 8px controls, 16px composer. Clear focus ring, text labels beside icons.
- Landing centers the composer and clearly labeled writing prompts; generated games supply their own art; studio operates around one large canvas; gallery foregrounds actual saved-game thumbnails.
- Motion only for loading and deliberate hover lift; respect reduced motion. Canvas has explicit play/pause and sound opt-in. Pixel assets render nearest-neighbor.
- Mobile: stacked studio, full width composer, wrapping toolbars, thumb-sized directional buttons. No horizontal page scrolling at 360px.
- Errors name a cause and recovery; pending states reflect real network/validation work. Never describe a fixture as an AI output.
