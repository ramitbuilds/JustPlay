# Project constraints

Preserve the MIT license and existing history. Use short lowercase commit messages (2–5 plain words). No paid services or assets. Never commit secrets; provider keys belong only in server environment bindings. Never execute model-generated code in the application origin or page. New games are AI-written source executed only in an opaque sandbox iframe and dedicated Worker with network blocked, bounded messages and a watchdog. Validate code artifacts and syntax on both sides; retain GameSpec only for legacy saves. Do not add keyword routing, game-family enums or preset fallback to new generation. Offline examples must be labeled. Run typecheck, lint, unit tests, build and relevant browser tests before handoff.
