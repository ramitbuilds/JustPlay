FUNCTIONAL REQUIREMENT: DO NOT FAKE GAME GENERATION
Different prompts must yield meaningfully different playable experiences. It is okay and desirable to support a constrained, reliable design space rather than pretending to generate arbitrary AAA games.

Start with 3 real game families:
- Side-scrolling platformer
- Top-down action/adventure/survival
- Endless runner

Build reusable modules for:
- player movement and physics
- animation and game state
- enemy patrol/chase/attack and hazards
- collisions and damage
- health, scoring, collectibles and power-ups
- projectiles, double jump, dash and checkpoints where applicable
- win/loss objectives and game restart
- camera, parallax, particles, transitions, sound feedback
- responsive controls and appropriate game pacing
- level generation with seeded deterministic placement and feasibility constraints

Games should vary by objective, difficulty, enemy composition, mechanics, movement, map layout, visual theme and asset selections. Never just swap title and background color on one canned game. Ensure levels can actually be completed; avoid impossible jumps and inaccessible collectibles.

AI -> GAMESPEC -> VALIDATED RUNTIME
1. User submits a natural-language request.
2. AI receives STRICT schema description, valid genres, mechanics and asset IDs.
3. AI returns structured GameSpec JSON, not arbitrarily executable JavaScript.
4. Zod and semantic checks validate schema, bounds, feasible objectives, asset references and mechanics.
5. Allow bounded parsing/repair attempts with clear errors on failure.
6. Deterministic level composer converts GameSpec into runtime content.
7. Phaser loads only validated local assets and builds the playable game.
8. On edits, AI receives current GameSpec plus requested changes, returns a revised validated spec, preserving unrelated features.
9. Save versioned games in IndexedDB; provide basic local export/import or encoded shareable GameSpec if feasible and within practical size limits.

Keep user-supplied prompts/data separate from system instructions and apply strict JSON boundaries. Do not execute AI-generated JS in the app's primary origin. If you later attempt sandboxed code-generation, it must be genuinely isolated, tested and optional; the stable GameSpec engine is the MVP.
